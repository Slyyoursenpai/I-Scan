# I-Scan
A simple Android app built with Java, that detects Cataracts using a smartphone camera or images from the phone gallery, using Deep Learning. 

The Machine Learning Model was created using Python and its library including Tensorflow. The portable TensorFlow Lite model allows it to be imported onto an Android app easily. 

The results show the presence or absence of Cataracts.
model_final.tflite is the ML model that is used here.
